# Чеклісти для тестування

## Модуль: Управління довідником предметів та академічних груп

### Функціональність
- [ ] Створення нового предмета з валідною назвою (напр. "Прикладна математика").
- [ ] Створення нової групи з визначенням її позиції у загальному списку (черговість відображення).
- [ ] Редагування назви існуючого предмета (зміни відображаються у списку).
- [ ] Редагування позиції групи у списку (зміна порядку сортування).
- [ ] Видалення предмета, який не задіяний у розкладі.
- [ ] Видалення групи, яка не має призначених занять.
- [ ] Перевірка роботи пошуку предмета за назвою.
- [ ] Перевірка роботи пошуку групи за назвою.
- [ ] Перевірка перемикача "Показати відключені" для перегляду архівних записів.
- [ ] Очищення форми створення натисканням кнопки "ОЧИСТИТИ".

### Негативні сценарії
- [ ] Спроба зберегти предмет або групу з порожньою назвою.
- [ ] Спроба видалити предмет, який уже призначений на пару в розкладі (має бути блок).
- [ ] Спроба видалити групу, для якої вже створений розклад (має бути блок).
- [ ] Створення дубліката предмета з назвою, яка вже існує в системі.
- [ ] Введення в поле назви занадто короткого тексту (1 символ).
- [ ] Введення в поле назви занадто довгих даних (понад 50 символів).

### UI/UX
- [ ] Перевірка наявності іконок керування (олівець, кошик, око) на кожній картці.
- [ ] Перевірка активності кнопки "ЗБЕРЕГТИ" лише після заповнення обов'язкових полів.
- [ ] Коректність відображення довгих назв (текст не має виходити за межі блоку/віджета).
- [ ] Візуальне виділення (напр. прозорість або інший колір) для відключених/архівних об'єктів.
